Adding First Tag - UX Options

Different ways to handle the "no tags yet" state and first tag addition

Option 1: Popover Below Icon

Click tag icon → Popover appears below the action bar

Review quarterly report

✓ Popover near the trigger

✓ Consistent with other popovers

○ May overlap content below

Option 2: Inline Search Row

✓ Recommended

Click tag icon → Search input appears as new row (like comments)

Review quarterly report

✓ Consistent with comments pattern

✓ Search is prominent and clear

✓ Tags shown as clickable pills

✓ No overlapping content

Option 3: Dropdown Anchored to Icon

Popover anchored directly below the tag icon button

Review quarterly report

✓ Clear relationship to trigger

✓ Compact

✗ Small hit target

✗ May go off-screen on mobile

Option 4: Full Section (like Due Date)

Expands to full-width section with tags and search

Review quarterly report

✓ Matches Due Date expanded pattern

✓ Plenty of space

Option 6: Quick Tag Pills

Shows recent/popular tags as quick-add pills + search

Review quarterly report

✓ One-click to add common tags

✓ Search available but secondary

○ Takes more space

Recommendation: Option 2 - Inline Search Row

Why this works:

  • Consistent with comments section pattern
  • Search input is prominent and above suggestions
  • Existing tags shown as clickable pills (quick add)
  • No popover overlap issues
  • Works well on mobile

Implementation:

  • Click tag icon → Expand inline row
  • Show: [tag icon] [search input]
  • Below: Quick-add pill buttons for existing tags
  • Type to filter + create option
  • Click outside or Escape to close
