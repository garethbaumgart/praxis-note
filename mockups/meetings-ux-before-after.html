4

Escape Key Hijacking Navigation

P1

Pressing Escape in the editor navigates back even when editing fields, popups are open, or the user just wants to dismiss something.

Before - Current Behavior
Escape key actions:
Esc While editing title Navigates away!
Esc While popup open Navigates + orphans popup!
Esc While editing transcript Navigates away!
Esc Nothing focused Navigates back (correct)

3 of 4 scenarios cause unexpected navigation

After - Proposed Behavior
Escape key cascade:
Esc While editing title Blurs input only
Esc While popup open Closes popup only
Esc While editing transcript Blurs textarea only
Esc Nothing focused Navigates back

Rule: Escape should always dismiss the nearest interactive layer first (popup > input focus > navigation).
