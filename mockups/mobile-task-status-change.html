Recommendation: Option 5 - Compact Icon Buttons

Why This Option?

  • • Integrates seamlessly with the metadata tab design (#156)
  • • Single tap to move - fastest interaction
  • • Color-coded buttons make destination clear
  • • Compact enough to not overwhelm cards
  • • Highly discoverable - visible on every card

Implementation Notes

  • • Show on mobile only (desktop uses drag)
  • • Add to right side of metadata tab row
  • • Use circular buttons matching tab style
  • • Color matches destination column
  • • Good aria-labels for accessibility

Alternative: Consider combining with Option 1 (swipe) for power users who discover the gesture. The buttons serve as the primary method while swipe is a shortcut.
