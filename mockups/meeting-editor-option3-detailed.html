Design Notes

Color Token Usage

  • bg-surface - Main dialog background
  • bg-surface-subtle - Card backgrounds, header, footer
  • bg-surface-muted - Hover states, disabled buttons
  • text-foreground - Primary text
  • text-foreground-secondary - Secondary text, labels
  • text-foreground-muted - Hints, placeholders
  • border-border - All borders
  • text-accent-foreground - Icons, accent text
  • bg-accent-solid - Primary buttons

Key Improvements Over Current

  • + All colors use semantic tokens (no hardcoded values)
  • + Cards provide clear visual grouping
  • + Quick date chips for common selections
  • + Consistent icon usage with accent color
  • + Better spacing and typography hierarchy
  • + Scrollable content area for long edit dialogs
  • + Distinct states for AI analysis (processing, failed, etc.)

Implementation Notes

  • 1. Replace PrimeNG Dialog default styling with custom classes using semantic tokens
  • 2. The "Pick Date" chip should open PrimeNG DatePicker in a dropdown/popover
  • 3. Time selects can use native selects or PrimeNG Dropdown
  • 4. AI Analysis component already exists - just needs card wrapper styling
