Summary: Recommended Approach

  • Style: Option C (Bordered Box) - consistent with other form inputs in the app
  • Placement: Full-width below the "Tasks" title, above kanban columns
  • Behavior: Real-time client-side filtering as user types
  • Keyboard: / to focus, Esc to clear
  • Clear button: Appears when text is entered
  • Match highlighting: Optional yellow highlight on matched text
