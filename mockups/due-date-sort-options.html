Behavior Notes

  • Drag-drop disabled: When sorting by due date, drag-and-drop reordering is disabled (tasks show the position they would have based on due date)
  • Null dates last: Tasks without due dates appear at the bottom when sorting by due date
  • Per-column setting: Each column can have its own sort preference (e.g., Todo by due date, InProgress manual)
  • Non-persistent: Sort preference resets to manual order on page refresh (no server-side storage needed)

Recommendation

Option A (Icon Button) is recommended for simplicity - it's the most minimal UI change that clearly communicates the toggle functionality. The highlighted state when active makes it obvious that a non-default sort is applied.

Option E (Dropdown) is better if you anticipate adding more sort options in the future (e.g., alphabetical, created date, priority).
