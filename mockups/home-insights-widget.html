Home Page Insights Widget - Design Options

5 design options for the Insights Summary Widget on the Home page (Issue #286).

Each option shows: (1) the widget with data, (2) the empty state. The widget sits below the quick-action cards on the Home page.

Context: The widget appears below the 3 quick-action cards (Notes, Tasks, Search) on the Home page. It should feel like a natural extension of the existing card design while being distinct enough to draw attention to insights data.

Option 1: Compact Metric Row

A single card with inline metrics in a horizontal row. Minimal footprint, scannable at a glance. Click anywhere to navigate to /insights.

Pros: Lightweight, doesn't dominate the page, quick to scan. Cons: Limited space for context or nudges, no visual trend indication.

Option 2: Highlight Card with Sparkline

Recommended

One featured metric with a sparkline visualization, plus 2 secondary stats. Draws the eye with a visual trend without overwhelming the page. Includes a nudge line for engagement.

Pros: Visual interest via sparkline, hierarchy of information, includes nudge/insight text. Cons: Slightly more complex to implement (needs SVG sparkline).

Option 3: Two-Column Split

Left side shows key metrics, right side shows a nudge/action item with context. Balanced layout that pairs data with actionable guidance.

Pros: Good information hierarchy, pairs metrics with context, action-oriented. Cons: Takes more vertical space, the two-column layout may feel heavy on a hub page.

Option 4: Single Headline Metric

Ultra-minimal design showing just one rotating headline insight with a bold number. Feels like a "daily digest" nudge rather than a dashboard widget.

Pros: Extremely lightweight, never overwhelming, encourages daily check-in. Cons: Only shows one metric at a time, may feel insufficient for engaged users.

Option 5: Mini Dashboard Cards

Three separate mini-cards below the quick actions, mirroring the quick-action card style. Each card is a metric with its own visual. Treats insights as first-class navigation items alongside Notes/Tasks.

Pros: Matches existing card grid pattern, each metric is independently scannable, familiar visual language. Cons: Takes the most space, may dilute the quick-action area, no single CTA — user must choose which to click.

Comparison Summary

Option Footprint Info Density Visual Appeal Complexity Best For
1. Compact Metric Row Small High Low Low Data-first users
2. Highlight + Sparkline ★ Medium Medium High Medium Best balance of data + visual
3. Two-Column Split Large High Medium Medium Actionable guidance focus
4. Single Headline Small Low Low Low Minimal nudge / daily digest
5. Mini Dashboard Cards Large High High Medium Insights as first-class nav

Recommendation: Option 2 (Highlight Card with Sparkline)

It strikes the best balance for a home page widget: visually engaging without dominating the page, shows enough data to be useful (one featured metric + two secondary), and the sparkline + nudge line give users a reason to click through to the full dashboard. It also keeps the Home page feeling like a hub rather than a dashboard itself.
