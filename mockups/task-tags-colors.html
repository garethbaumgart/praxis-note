Tag Color Context: Avoiding Conflicts

Consider how tag colors interact with existing column/status colors:

TODO Column

Uses Frost Cyan

IN PROGRESS Column

Uses Aurora Orange

DONE Column

Uses Aurora Green

Recommendation: Use Aurora Purple (current) or Frost Blue for tags.

✓ Purple: Distinct from all column colors, visually unique

✓ Blue: Distinct from columns, professional appearance

✗ Cyan: Conflicts with TODO column color

✗ Orange: Conflicts with IN PROGRESS column color

✗ Green: Conflicts with DONE column color

✗ Red: Conflicts with danger/overdue states

⚠ Yellow: Lower contrast, may be hard to read
