Why this approach works best:

  • • No tags: Subtle tag icon doesn't clutter, but provides clear affordance
  • • Has tags: Tags always visible, + button is right there for quick adds
  • • No redundancy: Icon OR inline tags, never both
  • • Consistent: Autocomplete works the same from both entry points
  • • Mobile-friendly: + button is always tappable when tags exist
