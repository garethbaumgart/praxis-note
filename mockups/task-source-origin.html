Recommended: Option 1 - Source Pill in Tab Bar

This option fits naturally into the existing task card UI pattern. The source pill sits alongside the Due Date and Comments tabs, maintaining visual consistency. It shows the source name and icon at all times without adding extra card height, and clicking navigates directly to the originating meeting or note.

Runner-up: Option 6 (Expandable Source Tab) if the tab bar becomes too crowded. This option trades immediate name visibility for a cleaner collapsed state, while offering a richer expanded view with source details.
