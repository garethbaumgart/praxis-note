Option A: Overflow "More" Menu Recommended

Show primary actions, hide secondary ones in a "more" menu. Responsive and clean.

Summary & Recommendations

Heading Selection

Recommended: Option 1 (Notion-style Dropdown)

Combines headings + block types in one dropdown. Clean, familiar, and extensible.

Toolbar Overflow

Recommended: Option A (Overflow Menu) + E (Responsive)

Show core tools, put extras in "..." menu. Auto-collapse on mobile for best UX.

Proposed Full Feature Set

Always Visible:

  • Block type dropdown
  • Bold, Italic, Underline
  • Link
  • Highlight
  • Lists (bullet, task)

In Overflow Menu:

  • Strikethrough
  • Inline code
  • Subscript/Superscript
  • Horizontal rule
  • Numbered list

Future Additions:

  • Image
  • Table
  • Code block
  • Text color
  • Text align
