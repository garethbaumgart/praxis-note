Primary: TipTap

Best overall fit for PraxisNote

Why TipTap?

  • • Built-in TaskList extension - checkboxes work out of the box
  • • JSON output perfectly matches Note domain model structure
  • • Headless architecture = full control over theming
  • • Excellent documentation and active community
  • • Future-proof: Y.js collaboration support when needed
  • • Same foundation as Notion, Linear, GitLab

Integration Path:

  1. Install ngx-tiptap and @tiptap/starter-kit
  2. Add TaskList and TaskItem extensions
  3. Create checkbox extraction service
  4. Build custom toolbar with PrimeNG components

Alternative: Editor.js

Good if you prefer block-based editing

When to choose Editor.js:

  • • You want Notion-style block manipulation
  • • Checklist items are always separate blocks (not inline)
  • • Clean JSON output with typed blocks
  • • Don't need real-time collaboration soon

Trade-offs:

  • • No official Angular wrapper (manual setup)
  • • Mobile experience is basic
  • • Checkboxes can't be inline with other text

For Markdown-First Users: Milkdown

If your target users are developers who love Markdown, Milkdown offers the best of both worlds:

Advantages:

  • • Type - [ ] for instant checkboxes
  • • Content is portable Markdown
  • • Works in any Markdown editor
  • • GFM task list is a standard

Considerations:

  • • Checkbox IDs need custom plugin
  • • Smaller community than TipTap
  • • Manual Angular integration

Not Recommended for PraxisNote

PrimeNG Editor

Despite being part of your UI library, the lack of any task list support makes it unsuitable. You'd need to build checkboxes as a separate component, breaking the unified editing experience.

Quill (standalone)

Building a custom checkbox blot requires significant effort. The Delta format is also harder to parse for checkbox extraction compared to TipTap's document tree.
