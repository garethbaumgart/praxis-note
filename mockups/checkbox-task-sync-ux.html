Checkbox ↔ Task Sync UX

The main feature of PraxisNote: Bidirectional sync between note checkboxes and kanban tasks.

Core Concept

Note Checkbox

User adds a checkbox in their note using TipTap's task list feature.

Bidirectional Sync

Kanban Task

Task appears on kanban board. Status changes sync back to checkbox.

Key Decision: Should creating a checkbox automatically create a task, or should users explicitly "promote" checkboxes to tasks?

Option 1: Auto-Sync

Every checkbox in a note automatically becomes a task on the kanban board.

Pros

  • • Zero friction - just type and it syncs
  • • Natural workflow matches how people think
  • • Always in sync, no manual steps

Cons

  • • Cluttered board with temporary/draft items
  • • No way to have "private" checkboxes
  • • Grocery lists become kanban tasks

Edge Cases to Handle

  • • Checkbox deleted: Task becomes "unlinked" but persists on board
  • • Task deleted: Checkbox becomes unlinked (reverts to regular checkbox)
  • • Note deleted: All linked tasks become unlinked
  • • Conflict: If both change simultaneously, last-write-wins with change indicator

Recommendation: Option 2 - Manual Promote with Enhancements

Why This Option?

  • ✓ Full user control over what becomes a task
  • ✓ Keeps kanban board clean and focused
  • ✓ Hover button is discoverable and quick
  • ✓ Bulk action handles multiple checkboxes efficiently
  • ✓ Status badges provide clear feedback
  • ✓ Click-through to task for full kanban features

Implementation Additions

  • • Add keyboard shortcut (⌘+⇧+T) for power users
  • • Add context menu for mobile (long-press)
  • • Add bulk "Create Tasks" button at bottom of note
  • • Status badge is clickable to open task
  • • Tasks inherit note's tags at creation time
