Checkbox Selection for Task Promotion

Design options for selecting individual checkboxes to promote as tasks. Refining Issue #205.

Current State & Goal

Current Implementation
  • - Backend API exists: POST /api/notes/{noteId}/checkboxes/{checkboxId}/promote
  • - Checkbox status endpoint exists for tracking linked state
  • - No UI to trigger promotion
  • - Previous mockup recommends "Manual Promote" approach
Goal

Design a UI that allows users to select individual checkboxes and promote them to tasks. The selection should support both single-item and bulk promotion workflows.

Option 1: Selection Mode Toggle

Enter a "selection mode" via toolbar button. Selection checkboxes appear next to each item. Bulk action bar at bottom.

Pros

  • + Clear separation between editing and selecting
  • + Explicit multi-select workflow

Cons

  • - Two clicks minimum (enter mode + select)
  • - May feel heavy for single-item promotion

Recommendation: Option 2 - Inline Action Icons

Why This Option?

  • + Fastest single-item promotion (one click)
  • + No mode switching - stays in editing flow
  • + Clean UI - actions hidden until needed
  • + Familiar hover pattern from many apps
  • + Low implementation complexity
  • + Status badges show linked state inline

Implementation Plan

  • + Hover reveals "Task" button on unlinked checkboxes
  • + Single click promotes immediately with toast feedback
  • + Shift+Click adds to selection for bulk promote
  • + Already-linked items show status badge (Todo/In Progress/Done)
  • + Status badge is clickable to navigate to task on board
  • + Mobile: Show action button always (no hover on touch)

Mobile Adaptation

Since hover doesn't work on touch devices, we'll show the "Task" button always visible on mobile (using a media query or touch detection). Alternatively, combine with Option 3 (Context Menu) using long-press on mobile to reveal the promote action in a bottom sheet.
