Insights Dashboard - Design Options

5 layout options for the Personal Insights page. Each shows summary cards + trend charts.

Option 1: Classic Dashboard

Recommended

Summary cards in a horizontal row at top, full-width charts stacked below. Clean, scannable, familiar dashboard pattern.

Pros: Immediately scannable, works well on all screen sizes, familiar pattern. Cons: Long vertical scroll for all charts.

Option 2: Two-Column Chart Grid

Summary cards at top, charts in a 2-column grid below. More compact vertical layout.

Pros: Less scrolling, shows more data at once. Cons: Charts are smaller, less detail visible. Doesn't work well on mobile (falls back to single column).

Option 3: Tabbed Chart Sections

Summary cards always visible. Charts organized by tabs (Speaking, Sentiment, Flags). One chart section visible at a time.

Pros: Minimal scrolling, focused view per category. Cons: Can't compare charts across categories at a glance. Extra click to switch tabs.

Option 4: Compact Cards with Inline Sparklines

Each metric gets a card containing both the summary stat AND a small sparkline chart. No separate chart section.

Pros: Very compact, each metric is self-contained, minimal scrolling. Cons: Charts are tiny (sparklines), hard to read detailed trends. Not ideal for red flag breakdown.

Option 5: Hero Chart with Stat Sidebar

Large featured chart on the left, vertical stat cards on the right. Clickable stat cards switch the main chart.

Pros: Dramatic, large chart is easy to read, interactive. Cons: Only one chart visible at a time, sidebar takes up space. Complex interaction model.
