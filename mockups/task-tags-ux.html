Comparison: Quick Reference

Option Alignment Pros Cons
1. Full-Width Pills Left edge (with flag/due date) Simple, full width utilization No visual link to tag concept
2. Tag Icon Prefix (Recommended) Icon at flag position, pills at title Mirrors flag row structure, clear hierarchy Slightly more complex
3. Compact Text Tags Left edge Very compact, minimal Less scannable, no pill affordance
4. Tags in Action Bar Inline with due date/comments Single row, compact Can get crowded, mixed concerns
5. Subtle Underline Under title (indented) Very subtle, doesn't compete Easy to miss
6. Rounded Box Container Full width, contained Clear grouping, feels like a section More visual weight, takes space
7. Minimal Left-Aligned Left edge (same as due date) Clean, no extra decoration May not stand out enough
8. Same Row as Due Date In action bar after separator Most compact, single row Crowded, overflow handling needed

Recommendation: Option 2 - Tag Icon Prefix

Why This Option?

  • * Mirrors the structure of the title row (icon + content)
  • * Tag icon aligns with flag position - visual consistency
  • * Pills align with title start - proper hierarchy
  • * Clear visual indicator that this row is "tags"
  • * Plus button naturally fits at end of pills
  • * Works well with many tags (icon stays top-aligned)

Implementation Notes

  • * Tag row only renders when task has tags
  • * Tag icon at same width as flag (w-5 h-5)
  • * Pills use flex-wrap for multiple tags
  • * Icon uses items-start for top alignment when wrapping
  • * Tag icon in action bar ONLY when no tags exist
  • * Consider hover X on pills for quick removal
