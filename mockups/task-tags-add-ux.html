Recommendation Summary

Trigger UX (how to start adding):

Option A (Plus Button) - Clean, minimal, consistent

  • Requires expand first (intentional)
  • Works on mobile and desktop

Picker UX (how to select/create):

Picker 1 (Autocomplete Dropdown) - Familiar, efficient

  • Type to filter existing tags
  • Shows usage count for context
  • Press Enter to create new tag

Future enhancements: Consider adding Picker 6 (Hash Syntax) for power users who want to add tags while typing task titles.
