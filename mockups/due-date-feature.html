10. Due Date Color Reference

State Color Example

Overdue (recent) red-500 Yesterday

Recommended Implementation

Display

  • • Icon + text inline (Section 5, Style A)
  • • Combined with elapsed time using "·" separator
  • • Color-coded by urgency (see color reference)
  • • Overdue tasks get subtle red border/background

Interaction

  • • Calendar icon on hover to add date (Section 2, Option 4)
  • • Click existing date badge to edit
  • • Quick options + PrimeNG calendar (Section 3, Option 4)
  • • Remove button in picker or confirmation pattern
