Summary: Meeting Editor Options

# Option Best For Desktop Friendly
1 Side-by-Side + Inline Calendar Desktop power users Excellent
2 Compact + Dropdown Calendar Smaller screens, quick entry Good
3 Card-Based Sections Visual organization Good
4 Horizontal Date Strip Week-focused scheduling Good
5 Minimal Floating Panel Rapid entry Limited
6 Split View (Google Calendar style) Full scheduling workflow Excellent
7 Tabbed Interface Complex meeting setup Good
8 Natural Language Input Power users who type fast Good (but complex)
9 Popover (Notion-like) Inline quick entry Limited
10 Side Drawer Edit mode with transcript Excellent
11 Current Design (Fixed) Minimal change approach Limited

Recommendation

Option 1 (Side-by-Side with Inline Calendar) is recommended for the "New Meeting" dialog because:

  • Calendar is always visible - no popup confusion
  • Uses desktop screen real estate effectively
  • Quick date shortcuts for common selections
  • Clear visual separation between form and calendar

For the Edit Meeting mode (which includes transcript), consider Option 10 (Side Drawer) as it provides the vertical space needed for the transcript textarea and AI analysis section.
