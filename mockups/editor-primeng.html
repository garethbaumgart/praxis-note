PrimeNG Editor

PrimeNG's built-in rich text editor component. Wrapper around Quill with PrimeNG styling.

Key Features

  • PrimeNG Integration: Consistent with your UI library
  • Zero Config: Works out of the box with PrimeNG
  • Theming: Automatically matches PrimeNG theme
  • Form Integration: Works with Angular reactive forms
  • Toolbar Customization: Configurable toolbar modules

Considerations

  • Quill Wrapper: Same limitations as Quill (no task lists)
  • Limited Extensibility: Hard to add custom formats
  • HTML Output: Stores content as HTML string
  • Opinionated: Less control over UI than headless options
  • Bundle: Adds Quill dependency (~43KB)

Task List Support (Critical Limitation)

PrimeNG Editor does NOT support task lists

Since PrimeNG Editor wraps Quill, it inherits Quill's limitation of having no built-in checkbox/task list support. Custom formats are difficult to add through PrimeNG's abstraction layer.

Workaround: Separate checkbox component outside editor

Angular Integration

Simple usage with Angular signals
// note-editor.component.ts
import { Component, signal } from '@angular/core';
import { EditorModule } from 'primeng/editor';

@Component({
  selector: 'app-note-editor',
  standalone: true,
  imports: [EditorModule],
  template: `
    <p-editor
      [style]="{ height: '300px' }"
      [(ngModel)]="content"
      (onTextChange)="onContentChange($event)">
      <ng-template pTemplate="header">
        <span class="ql-formats">
          <button type="button" class="ql-bold"></button>
          <button type="button" class="ql-italic"></button>
        </span>
        <span class="ql-formats">
          <button type="button" class="ql-list" value="bullet"></button>
        </span>
      </ng-template>
    </p-editor>

    <!-- Separate task list (workaround) -->
    <div class="task-list-container">
      @for (task of tasks(); track task.id) {
        <div class="task-item">
          <p-checkbox
            [binary]="true"
            [(ngModel)]="task.checked"
            (onChange)="onTaskChange(task)">
          </p-checkbox>
          <span>{{ task.text }}</span>
        </div>
      }
    </div>
  `
})
export class NoteEditorComponent {
  content = '';
  tasks = signal<Task[]>([]);

  onContentChange(event: any) {
    // event.htmlValue contains the HTML string
    console.log(event.htmlValue);
  }

  // Tasks managed separately from editor content
  onTaskChange(task: Task) {
    this.tasks.update(tasks =>
      tasks.map(t => t.id === task.id ? { ...t, checked: task.checked } : t)
    );
  }
}
