TipTap Editor

Headless, extensible rich text editor built on ProseMirror. Full control over UI and functionality.

Key Features

  • Headless: Complete control over UI - no forced styles
  • Extensible: 50+ official extensions, easy custom extensions
  • Task Lists: Built-in checkbox extension perfect for notes
  • Collaboration: Real-time collab via Y.js integration
  • TypeScript: Full TypeScript support
  • Framework Support: Vue, React, Angular wrappers available

Considerations

  • Bundle Size: ~45KB min+gzip (core + common extensions)
  • Learning Curve: ProseMirror concepts needed for custom extensions
  • Angular: Uses ngx-tiptap wrapper (community maintained)
  • Output: JSON (native), HTML, Markdown (with extension)

Angular Integration Example

Using ngx-tiptap with Angular Signals
// note-editor.component.ts
import { Component, computed, inject, input, output, signal } from '@angular/core';
import { Editor } from '@tiptap/core';
import { NgxTiptapModule } from 'ngx-tiptap';
import StarterKit from '@tiptap/starter-kit';
import TaskList from '@tiptap/extension-task-list';
import TaskItem from '@tiptap/extension-task-item';

@Component({
  selector: 'app-note-editor',
  standalone: true,
  imports: [NgxTiptapModule],
  template: `
    <div class="editor-toolbar">
      <button (click)="toggleBold()" [class.active]="editor.isActive('bold')">B</button>
      <button (click)="toggleTaskList()">Checkbox</button>
    </div>
    <tiptap-editor [editor]="editor" (contentChange)="onContentChange($event)"></tiptap-editor>
  `
})
export class NoteEditorComponent {
  readonly content = input<string>('');
  readonly contentChange = output<string>();

  editor = new Editor({
    extensions: [
      StarterKit,
      TaskList,
      TaskItem.configure({ nested: true }),
    ],
    content: this.content(),
    onUpdate: ({ editor }) => {
      this.contentChange.emit(JSON.stringify(editor.getJSON()));
    },
  });

  toggleBold() {
    this.editor.chain().focus().toggleBold().run();
  }

  toggleTaskList() {
    this.editor.chain().focus().toggleTaskList().run();
  }

  // Extract checkboxes for syncing with domain
  getCheckboxes(): Checkbox[] {
    const doc = this.editor.getJSON();
    return this.extractTaskItems(doc);
  }
}
