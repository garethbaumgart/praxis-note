Task Metadata Tabs - Google Home Style

Inspired by Google Home's expandable icon tabs for Due Date and Comments

Reference: Google Home Pattern

Key UX Elements
  • 1. Horizontal scrollable icon tabs: Circular icons for each category (Favorites, Devices, Cameras, Lights, Wi-Fi)
  • 2. Selected state expands: Icon becomes a pill shape with icon + text label, highlighted background
  • 3. Content area changes: The area below shows content relevant to the selected tab
  • 4. Unselected tabs: Just the icon in a subtle circular background

For PraxisNote tasks: Apply this pattern to Due Date, Comments, and potentially other metadata (Priority, Tags, etc.)

Comparison: Quick Reference

Option Pattern Pros Cons
1. Full Tab Bar (Recommended) Google Home style Most visual, familiar mobile pattern, clear affordance Takes more vertical space
2. Enhanced Current Icon row with expand Minimal change, compact Less discoverable expand action
3. Horizontal Split Traditional tabs Clear, familiar web pattern Feels more desktop-y, less playful
4. Segmented Control iOS style Modern, clean, shows both at once Limited to 2-3 tabs max
5. Floating Pills Badge/chip style Very compact, good for quick info Expand action less obvious
6. Bottom Sheet Mobile drawer Most room for content, native mobile More disruptive, hides card context

Recommendation: Option 1 - Full Tab Bar

Why This Option?

  • • Directly matches the Google Home pattern you referenced
  • • Clear visual affordance - users know they can tap icons
  • • Selected state (expanded pill) is immediately recognizable
  • • Works well on mobile and desktop
  • • Easily extensible for future metadata (tags, priority, etc.)

Implementation Notes

  • • Use Angular animations for smooth expand/collapse
  • • Color-code by meaning (amber=due date, primary=comments)
  • • Badge counts on collapsed icons for quick scanning
  • • Only one tab expanded at a time (exclusive selection)
  • • Tap selected tab again to collapse
