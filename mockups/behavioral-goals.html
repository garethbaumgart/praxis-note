Issue #283 — 5 design options for the goals section on the Insights page

Each option shows: goals list, add goal dialog, and how it integrates with the existing Insights page. The goals section sits between the header/filters and the trend charts.

Option 1: Card Grid with Ring Progress

Each goal is a standalone card with a circular progress ring, streak badge, and pass/fail dot track. Clean and scannable.

Pros: Highly scannable, each goal is self-contained, ring progress is visually striking, dot track shows recent history at a glance.

Cons: Takes more vertical space with 3+ goals, ring progress may feel heavy on mobile, less room for detail per card.

Recommendation: Option 2 — Compact List with Segmented Progress

  • Segmented progress bars communicate pass/fail per meeting — the core information users need
  • Compact rows scale well from 1 goal to 10+ without overwhelming the insights page
  • Matches the list-based patterns already used in Tasks and Meetings pages
  • Streak badges are inline and unobtrusive but visible
  • Suggestion row integrates naturally as a dashed-border variant
  • Hover reveals chevron for detail view navigation — progressive disclosure
  • Mobile-friendly: single column stacks naturally
