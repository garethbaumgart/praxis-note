Summary: Back-to-Back Workflow

1
Capture: One-click record. Optionally add title. Stop when meeting ends. Move on immediately.
2
Process: Audio uploads in background → Whisper transcribes → Claude analyzes → Audio deleted. ~2-3 min total.
3
Notify: Badge shows unreviewed count. Optional browser notification. End-of-day digest.
4
Review: When you have time, review meetings. Add/edit title & attendees. Create tasks from actions. Mark as reviewed.

Recommended Approach

  • • List View: Option 1 - Daily Grouped List (from previous mockup)
  • • Capture: Option 1 - Minimal Capture Mode with big record button
  • • Review: Single page with editable fields and action items prominent
  • • No audio storage: Transcribe immediately, delete audio file
