Meeting Time Picker UX Options

15 design options to simplify the meeting time picker. All options default to the nearest 30-minute interval.

Options 11-15 are hybrid designs that support both typing and clicking/picking.

Default time logic: Round to nearest 30 min — e.g. 6:15 PM → 6:30 PM, 6:14 PM → 6:00 PM, 6:45 PM → 7:00 PM

Recommendation: Option 11 (Editable Combobox)

The editable combobox gives the best of both worlds: users can type any time ("6:30p", "18:30", "630pm") and it filters the dropdown in real-time, or they can click the chevron to browse all 30-min interval slots. It replaces 3 dropdowns with 1 compact input, uses PrimeNG's p-autoComplete or p-select [editable]="true", and handles the 95% case (pick a 30-min slot) just as fast as a plain dropdown while also supporting the 5% case (exact custom times) without any extra UI. The default time auto-populates to the nearest 30 minutes.

Default Time Logic (All Options)

Round to nearest 30-minute boundary. This logic applies to all options above when a new meeting is created.

function getDefaultMeetingTime(): Date {
  const now = new Date();
  const minutes = now.getMinutes();

  // Round to nearest 30 min
  // 0-14 → :00, 15-44 → :30, 45-59 → next hour :00
  if (minutes < 15) {
    now.setMinutes(0, 0, 0);
  } else if (minutes < 45) {
    now.setMinutes(30, 0, 0);
  } else {
    now.setHours(now.getHours() + 1);
    now.setMinutes(0, 0, 0);
  }

  return now;
}

// Examples:
// 6:14 PM → 6:00 PM  (14 < 15, round down)
// 6:15 PM → 6:30 PM  (15 >= 15, round to :30)
// 6:44 PM → 6:30 PM  (44 < 45, stay at :30)
// 6:45 PM → 7:00 PM  (45 >= 45, round up)
