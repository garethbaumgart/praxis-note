Comparison

Option Style Pros Cons
1. Full Pill (Recommended) Icon + Label + Badge Clear, matches task tabs, highly visible Takes more horizontal space
2. Compact Pill Icon + Count only Space efficient Less clear without label
3. Circular + Expand Circle, expands on hover Exact Google Home behavior Hover doesn't work on mobile
4. Segmented Toggle Both options visible Clear state, easy toggle Takes most space, may be redundant
5. Text Link Minimal text + icon Least visual weight Doesn't look like a button

Recommendation: Option 1 - Full Pill with Badge

Why This Option?

  • • Directly matches the task metadata tab pill style
  • • Clear visual affordance - obviously a button
  • • Color-coded to indicate action (amber = archive, green = done)
  • • Badge shows count at a glance
  • • Works well on both mobile and desktop

Implementation

  • • Replace PrimeNG p-button with custom pill button
  • • Use Tailwind classes: rounded-full h-7 px-3
  • • Background: bg-archive / bg-done
  • • Badge: bg-{color}-foreground/20 rounded-full px-1.5
  • • Smooth hover transition
