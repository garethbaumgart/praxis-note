Recommendation: Option 1 (Inline Search Row)

Option 1 provides the best balance of simplicity and usability:

  • + Minimal UI change - just adds input inline with existing tags
  • + Dropdown appears naturally below the input
  • + Works well for both first tag and additional tags
  • + No positioning/overflow issues like tooltips
  • + Consistent with how other inline inputs work in the app
