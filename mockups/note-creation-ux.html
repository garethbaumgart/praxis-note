Note Creation & Editing UX Options

5 approaches to create and view notes

Option 1: Google Keep Style - Inline Expand

Recommended

Click "Take a note" to expand inline. No dialog. Cards show preview, click to edit in place.

Pros:

  • Familiar Google Keep pattern users know
  • No modal interruption - stays in flow
  • Quick entry and exit
  • See notes while editing

Cons:

  • Limited editor space when many notes visible
  • May need to scroll to see full editor

Option 2: Full Page Editor (Notion Style)

Alternative

Click a note or "New" to navigate to a dedicated full-page editor. No cards - list view in sidebar.

Recommendation Summary

Option 1 (Google Keep Style) is recommended because:

  • Users already know this pattern from Google Keep
  • Minimal change from current architecture - just remove the dialog
  • Quick and fluid note creation without modal interruption
  • Works well on both mobile and desktop

Option 2 (Notion Style) would be ideal if you plan to support very long notes with complex formatting, but requires significant architectural changes.

Option 3 (Slide-over) is a good middle ground if users want more editing space than inline but less commitment than full page.
