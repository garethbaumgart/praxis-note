## General

- **Is PraxisNote free?** — PraxisNote is an open-source project. You can self-host it at no cost.
- **What browsers are supported?** — PraxisNote works in all modern browsers (Chrome, Firefox, Safari, Edge).
- **Does PraxisNote work on mobile?** — Yes, the interface is fully responsive and works on phones and tablets.
