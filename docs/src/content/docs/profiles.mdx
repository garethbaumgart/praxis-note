## Overview

PraxisNote supports multiple profiles, allowing you to maintain separate workspaces for different contexts (e.g., work and personal). You can also link accounts so multiple sign-in methods access the same data.

## Key Capabilities

- Create and switch between multiple profiles
- Link additional accounts to your primary profile
- Generate link codes for connecting accounts across devices
- Profile-specific data isolation (tasks, notes, meetings stay separate)
- Quick profile switcher in the sidebar
