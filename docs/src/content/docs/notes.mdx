## Overview

PraxisNote's note editor is a rich text workspace for capturing ideas, meeting notes, and documentation. Notes save automatically as you type and support a range of formatting options.

## Key Capabilities

- Rich text editing with headings, bold, italic, and lists
- Slash commands for quick formatting and block insertion
- Checkbox lists that can sync with your task board
- Tag support for organizing notes alongside tasks and meetings
- PDF export for sharing notes outside PraxisNote
- Automatic saving with last-edited timestamp

## Slash Commands

Type `/` in the editor to open the command menu. You can type the command name or a short alias to quickly filter and select a command.

| Command | Aliases | Description |
|---------|---------|-------------|
| Heading 1 | `h1` | Large section heading |
| Heading 2 | `h2` | Medium section heading |
| Heading 3 | `h3` | Small section heading |
| Bullet List | `ul`, `bullets` | Unordered bullet list |
| Numbered List | `ol`, `numbers` | Ordered numbered list |
| Task List | `task`, `checklist` | Checkbox list (syncs with tasks) |
| Toggle Section | `toggle`, `collapse`, `details` | Collapsible content section |
| Blockquote | `quote`, `bq` | Indented quote block |
| Code Block | `code`, `cb` | Syntax-highlighted code block |
| Table | | 3x3 table with header row |
| Image | `img`, `pic` | Insert an image by URL |
| Divider | `hr`, `line`, `separator` | Horizontal rule |
| Date | | Insert today's date as an inline date chip |
| Today | | Insert today's date as an inline date chip |
| Tomorrow | | Insert tomorrow's date as an inline date chip |

Date chips render as styled inline elements with a calendar icon. Click a date chip to open a popover with quick-pick buttons (Today, Tomorrow, Next Mon) and a date picker to change the date.

For example, typing `/h1` will filter the menu to show "Heading 1", and typing `/task` will show "Task List".
